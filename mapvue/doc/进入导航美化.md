## 一、最核心的问题诊断（为什么现在“怪”）

### 1️⃣ 顶部步骤导航「太重 + 太幼态」

* emoji / icon 太多
* 圆形节点 + 高饱和绿
* 视觉上像「新手教程 / 儿童产品」

👉 **与你的“科学 / 专业 / 长期使用”目标是反的**

---

### 2️⃣ 表单像“填资料”，不像“建立模型”

现在用户心理是：

> “我在被要求填信息”

而不是：

> “系统在帮我建立身体模型”

---

### 3️⃣ 输入框太“白 + 框重”

* 大白底
* 粗边框
* 像后台管理系统，不像消费级健康产品

---

## 四、标题与文案：从「填写」→「建模」

### ❌ 现在

> 填写身体数据
> 帮助我们更准确地计算您的基础代谢…

太像说明书了。

---

### ✅ 建议文案（非常重要）

#### 主标题

```
建立你的身体模型
```

#### 副标题（小一号灰色）

```
用于更准确地估算每日消耗与运动强度
```

👉 用户立刻会觉得：
**“我不是在填表，我是在配置一个智能系统”**

---

## 五、输入框设计（高级感的关键）

### ❌ 现在的问题

* 框太明显
* 对比太强
* 不够“呼吸感”

---

### ✅ 推荐输入样式（非常通用）

#### 样式原则

* **无边框 / 极浅边框**
* 底色略灰
* 圆角小一点（不要太“可爱”）

#### 示例（文字描述）

```
身高
[ 186 cm ]   ← 浅灰背景，无明显边框

体重
[ 67.5 kg ]

年龄
[ 21 ]
```

**细节建议**

* 单位用浅灰小字，别占位
* 数字字号 > label
* label 用中灰，不要纯黑

---

## 六、性别选择：去 emoji，留“选择感”

### ❌ 现在的问题

* emoji 太娱乐化
* 边框太粗

---

### ✅ 改成「轻选择卡片」

```
性别
[ 男 ]    [ 女 ]
```

#### 状态区分

* 选中：浅绿底 + 细描边
* 未选：透明底 + 灰描边

📌 **去掉 emoji 后，专业度立刻上来**

---

## 七、底部按钮：现在是对的，但可以更克制

### 现在

* 黑色主按钮 OK
* 但有点“重”

### 建议

* 主按钮：深灰（不是纯黑）
* 文案建议：
  **「继续」** 比「下一步」更人性

```
[ 上一步 ]      [ 继续 ]
```
