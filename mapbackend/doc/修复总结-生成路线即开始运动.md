# 修复总结：生成路线即开始运动

## ✅ 修复内容

### 1. 后端逻辑修改

**文件**: `mapbackend/src/routes/route.js`

**修改内容**:
1. **生成路线时自动设置为 `started` 状态**
   - 之前：状态为 `generated`，需要用户点击"开始运动"按钮后才变为 `started`
   - 现在：生成路线时直接设置为 `started` 状态

2. **立即创建 FoodRecord 消耗记录**
   - 在保存路线后，立即创建 `type='consume'` 的 FoodRecord 记录
   - 使用路线的估算消耗、距离、时长
   - 关联路线ID（`metadata.routeId`）

3. **立即更新 User.totalStats**
   - 累计消耗：`totalCaloriesBurned += route.estimatedCalories`
   - 累计时长：`totalExerciseMinutes += Math.round(route.duration / 60)`
   - 累计距离：`totalDistance += parseFloat((route.distance / 1000).toFixed(2))`

**关键代码**:
```javascript
// 生成路线时自动设置为 started
status: 'started'

// 设置开始时间
savedRoute.startedAt = new Date();

// 创建消耗记录
consumeRecord = await FoodRecord.create({
  user: req.user._id,
  name: exerciseName,
  calories: savedRoute.estimatedCalories,
  type: 'consume',
  duration: Math.round(savedRoute.duration / 60),
  distance: parseFloat((savedRoute.distance / 1000).toFixed(2)),
  exerciseType: savedRoute.sportType,
  metadata: { routeId: savedRoute._id },
  time: new Date()
});

// 更新用户累计统计
user.totalStats.totalCaloriesBurned += savedRoute.estimatedCalories;
user.totalStats.totalExerciseMinutes += Math.round(savedRoute.duration / 60);
user.totalStats.totalDistance += parseFloat((savedRoute.distance / 1000).toFixed(2));
```

### 2. 前端逻辑修改

**文件**: `mapvue/src/components/exercise/ExercisePlanModal.vue`

**修改内容**:
1. **简化 `openAmap` 函数**
   - 移除了调用 `startExercise` API 的逻辑（因为路线生成时已经自动开始）
   - 只保留触发 `exercise-started` 事件，通知前端组件刷新数据

2. **触发全局事件**
   - 同时触发本地事件（`emit('exercise-started')`）和全局事件（`window.dispatchEvent`）
   - 确保所有组件都能收到刷新通知

**关键代码**:
```typescript
// 触发事件，通知父组件刷新数据
emit('exercise-started', {
  routeId: generatedRoute.value.routeId,
  calories: Number(generatedRoute.value.calories) || 0,
  distance: generatedRoute.value.distance || '0.0',
  duration: Number(generatedRoute.value.duration) || 0
})

// 同时触发全局事件，让所有组件都能收到
window.dispatchEvent(new CustomEvent('exercise-started', {
  detail: {
    routeId: generatedRoute.value.routeId,
    calories: Number(generatedRoute.value.calories) || 0,
    distance: generatedRoute.value.distance || '0.0',
    duration: Number(generatedRoute.value.duration) || 0
  }
}))
```

### 3. 前端组件自动刷新

**文件**: 
- `mapvue/src/components/home/DailySummaryCard.vue`
- `mapvue/src/components/profile/StatsCard.vue`

**修改内容**:
1. **添加事件监听**
   - 在 `onMounted` 中监听 `exercise-started` 事件
   - 在 `onUnmounted` 中移除事件监听
   - 收到事件时自动调用 `loadDailySummary()` 或 `loadUserStats()` 刷新数据

**关键代码**:
```typescript
onMounted(() => {
  loadDailySummary()
  // 监听运动开始事件，自动刷新数据
  window.addEventListener('exercise-started', loadDailySummary)
})

onUnmounted(() => {
  window.removeEventListener('exercise-started', loadDailySummary)
})
```
