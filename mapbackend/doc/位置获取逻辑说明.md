# 位置获取逻辑说明

## 概述

位置获取服务 (`locationService.js`) 负责获取用户的真实位置信息，支持多种获取方式，按优先级顺序如下：

## 位置获取优先级

### 1. 从请求体中获取（最高优先级）
- **来源**: `req.body.location`
- **说明**: 前端通过浏览器定位 API（如 `navigator.geolocation`）获取用户位置后，通过请求体传递
- **格式**: 
  ```json
  {
    "location": {
      "lat": 31.230416,
      "lng": 121.473701,
      "city": "上海"
    }
  }
  ```

### 2. 从查询参数中获取
- **来源**: `req.query.lat`, `req.query.lng`, `req.query.city`
- **说明**: 通过 URL 查询参数传递位置信息
- **示例**: `/api/route/generate?lat=31.23&lng=121.47&city=上海`

### 3. 从用户数据库中获取
- **来源**: `user.location`（MongoDB 用户文档）
- **说明**: 如果用户之前保存过位置信息，则使用数据库中的位置
- **格式**: 
  ```javascript
  {
    location: {
      lat: 31.230416,
      lng: 121.473701,
      city: "上海"
    }
  }
  ```

### 4. 使用高德地图 IP 定位（最后手段）
- **来源**: 高德地图 IP 定位 API
- **说明**: 通过客户端 IP 地址定位用户所在城市，然后通过地理编码获取城市中心坐标
- **API**: `https://restapi.amap.com/v3/ip?key=xxx&ip=xxx`
- **流程**:
  1. 从请求头中提取客户端 IP（支持 `X-Forwarded-For`, `X-Real-IP`）
  2. 调用高德 IP 定位 API 获取省份、城市、城市编码
  3. 调用高德地理编码 API 将城市名称转换为坐标
  4. 返回城市中心坐标

### 5. 默认位置（仅当所有方法都失败时）
- **位置**: 北京天安门（39.908823, 116.397470）
- **说明**: 仅在所有定位方法都失败时使用，会返回警告信息

## 位置获取流程

```

  ↓

  ↓ (有)

```

## 代码位置

### 主要文件
- `src/services/locationService.js` - 位置获取服务
- `src/routes/route.js` - 路由处理，调用位置获取服务
- `src/services/routeService.js` - 路线生成服务，接收位置信息

### 关键函数

#### `getUserLocation(req, user)`
- **功能**: 获取用户位置信息（主入口函数）
- **参数**: 
  - `req`: Express 请求对象
  - `user`: 用户数据库对象
- **返回**: `Promise<Object>` - 位置信息对象
  ```javascript
  {
    lat: 31.230416,
    lng: 121.473701,
    city: "上海",
    source: "request" | "query" | "database" | "ip_location" | "default"
  }
  ```

#### `getLocationByIP(ip)`
- **功能**: 通过 IP 地址获取位置
- **参数**: `ip` - IP 地址字符串
- **返回**: `Promise<Object>` - 位置信息对象

#### `getClientIP(req)`
- **功能**: 从请求中提取客户端 IP 地址
- **参数**: `req` - Express 请求对象
- **返回**: `string` - IP 地址

## 使用示例

### 在路由中使用

```javascript
const { getUserLocation } = require('../services/locationService');

router.post('/generate', protect, async (req, res, next) => {
  // 获取用户数据
  const user = await User.findById(req.user._id);
  
  // 获取位置信息
  const location = await getUserLocation(req, user);
  
  // 使用位置信息生成路线
  // ...
});
```

### 前端传递位置信息

```javascript
// 方式1: 通过请求体传递
fetch('/api/route/generate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    preferences: { ... },
    location: {
      lat: 31.230416,
      lng: 121.473701,
      city: "上海"
    }
  })
});

// 方式2: 通过查询参数传递
fetch('/api/route/generate?lat=31.23&lng=121.47&city=上海', {
  method: 'POST',
  // ...
});
```

## 调试信息

位置获取服务会输出详细的日志信息，包括：
- 位置获取的优先级顺序
- 使用的定位方法
- 获取到的位置信息
- 错误和警告信息

查看控制台输出即可了解位置获取的完整流程。

## 注意事项

1. **前端定位**: 建议前端使用浏览器定位 API 获取精确位置，这是最准确的方式
2. **IP 定位精度**: IP 定位只能定位到城市级别，精度较低
3. **位置缓存**: 如果从请求中获取到位置，会自动更新到用户数据库中
4. **默认位置**: 使用默认位置时会返回警告信息，提醒用户位置可能不准确
