# 本地开发环境位置获取说明

## 问题说明

在本地开发环境中（`localhost` 或 `127.0.0.1`），由于 IP 地址是本地回环地址，高德地图 IP 定位 API **无法获取真实位置**。

### 为什么会失败？

1. **本地 IP 地址**：`127.0.0.1` 或 `::1` 是本地回环地址，不代表真实地理位置
2. **高德 API 限制**：高德地图 IP 定位 API 无法定位本地 IP 地址
3. **返回数据格式**：即使 API 返回成功，`data.city` 可能不是字符串类型，导致 `replace` 方法失败

## 解决方案

### 方案 1：前端使用浏览器定位 API（推荐）

前端通过浏览器的 `navigator.geolocation` API 获取用户真实位置，然后传递给后端。

#### 前端代码示例

```javascript
// 获取用户位置
navigator.geolocation.getCurrentPosition(
  (position) => {
    const location = {
      lat: position.coords.latitude,
      lng: position.coords.longitude
    };
    
    // 调用后端 API，传递位置信息
    fetch('/api/route/generate', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${token}`
      },
      body: JSON.stringify({
        preferences: {
          // ... 其他偏好设置
        },
        location: location  // 传递位置信息
      })
    })
    .then(res => res.json())
    .then(data => {
      console.log('路线生成成功:', data);
    });
  },
  (error) => {
    console.error('定位失败:', error);
    // 定位失败时的处理
  },
  {
    enableHighAccuracy: true,  // 使用高精度定位
    timeout: 10000,             // 超时时间 10 秒
    maximumAge: 0              // 不使用缓存
  }
);
```

#### 注意事项

1. **HTTPS 要求**：浏览器定位 API 在非 HTTPS 环境下可能无法使用（iOS 10+ 和部分 Android 版本）
2. **用户授权**：需要用户授权才能获取位置信息
3. **权限提示**：首次使用时会弹出位置权限请求

### 方案 2：通过查询参数传递位置

如果无法使用浏览器定位 API，可以通过 URL 查询参数传递位置：

```javascript
// 手动设置位置（例如：上海）
const lat = 31.230416;
const lng = 121.473701;
const city = '上海';

fetch(`/api/route/generate?lat=${lat}&lng=${lng}&city=${city}`, {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${token}`
  },
  body: JSON.stringify({
    preferences: {
      // ... 偏好设置
    }
  })
});
```

### 方案 3：使用高德地图 JS API（前端）

如果前端集成了高德地图 JS API，可以使用高德的定位插件：

```javascript
// 使用高德地图定位插件
AMap.plugin('AMap.Geolocation', function() {
  const geolocation = new AMap.Geolocation({
    enableHighAccuracy: true,
    timeout: 10000,
    zoomToAccuracy: true
  });

  geolocation.getCurrentPosition(function(status, result) {
    if (status === 'complete') {
      const location = {
        lat: result.position.lat,
        lng: result.position.lng,
        city: result.addressComponent.city
      };
      
      // 调用后端 API
      fetch('/api/route/generate', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'Authorization': `Bearer ${token}`
        },
        body: JSON.stringify({
          preferences: { /* ... */ },
          location: location
        })
      });
    } else {
      console.error('定位失败:', result);
    }
  });
});
```

## 位置获取优先级

后端会按以下优先级获取位置信息：

1. **请求体中的位置** (`req.body.location`) - 最高优先级
2. **查询参数中的位置** (`req.query.lat/lng`)
3. **用户数据库中的位置** (`user.location`)
4. **IP 定位** - 仅在生产环境有效
5. **默认位置（北京）** - 仅当所有方法都失败时使用

## 调试建议

### 1. 检查位置信息是否正确传递

在后端日志中查看：

```

║   📍 开始获取用户位置信息                             ║
╚═══════════════════════════════════════════════════════╝
✅ 从请求体中获取位置信息
📍 位置: {
  "lat": 31.230416,
  "lng": 121.473701,
  "city": "上海"
}
```

### 2. 检查是否为本地 IP

如果看到以下日志，说明检测到了本地 IP：

```
⚠️ 检测到本地 IP 地址，无法使用 IP 定位
💡 提示：本地开发时，请通过以下方式提供位置信息：
   1. 前端通过浏览器定位 API 获取位置并传递
   2. 在请求体中包含 location 参数
   3. 在查询参数中包含 lat/lng 参数
```

### 3. 查看完整的位置获取流程

后端会输出详细的位置获取日志，包括：
- 使用的定位方法
- 获取到的位置信息
- 错误和警告信息

## 生产环境

在生产环境中，如果用户没有提供位置信息，系统会：

1. 尝试从用户数据库中获取之前保存的位置
2. 使用 IP 定位获取用户所在城市（仅限公网 IP）
3. 如果都失败，使用默认位置（北京）

## 总结

**本地开发时**：
- ✅ 推荐使用浏览器定位 API 获取位置
- ✅ 通过请求体或查询参数传递位置信息
- ❌ 不要依赖 IP 定位（本地 IP 无法定位）

**生产环境**：
- ✅ 优先使用前端传递的位置信息（最准确）
- ✅ 可以使用 IP 定位作为备选方案
- ✅ 自动保存用户位置到数据库，下次使用
