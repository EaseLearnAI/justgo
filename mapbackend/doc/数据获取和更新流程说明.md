# 数据获取和更新流程说明

## 🔍 问题分析

### 当前问题
1. **路线数据已保存到数据库**，但前端没有显示
2. **API路径错误**：`POST /api/route/generate/:routeId/start` 返回 404
3. **统计查询逻辑**：只查询 `started` 或 `completed` 状态的路线

### 根本原因
- 路线刚生成时状态是 `generated`
- 只有点击"启动高德地图开始运动"后，状态才会变成 `started`
- 如果 start 接口调用失败（404），状态就不会更新
- 统计API只查询 `started` 或 `completed` 状态的路线，所以查不到数据

## 📊 数据获取流程

### DailySummaryCard.vue - 今日热量摘要

**API**: `GET /api/stats/daily-summary`

**数据来源**:
1. **FoodRecord**: 今日所有 `type='consume'` 的记录
2. **ExerciseRoute**: 今日所有 `status='started'` 或 `status='completed'` 的路线

**计算公式**:
```
exercise = FoodRecord消耗 + ExerciseRoute消耗
netCalories = intake - exercise - baseMetabolism
```

**后端查询逻辑**:
```javascript
// 1. 获取 FoodRecord 消耗
const todayStats = await FoodRecord.getTodayStats(req.user._id);

// 2. 获取今日路线（所有状态）
const todayRoutes = await ExerciseRoute.find({
  user: req.user._id,
  $or: [
    { generatedAt: { $gte: today, $lt: tomorrow } },
    { startedAt: { $gte: today, $lt: tomorrow } },
    { completedAt: { $gte: today, $lt: tomorrow } }
  ]
});

// 3. 过滤出已开始/已完成的路线
const activeRoutes = todayRoutes.filter(route => 
  route.status === 'started' || route.status === 'completed'
);

// 4. 累加路线消耗
let routeCalories = 0;
activeRoutes.forEach(route => {
  routeCalories += route.actualCalories || route.estimatedCalories || 0;
});

// 5. 合并两个数据源
const totalExercise = todayStats.consume + routeCalories;
```

### StatsCard.vue - 用户累计统计

**API**: `GET /api/stats/user-stats`

**数据来源**:
1. **FoodRecord**: 所有 `type='consume'` 的记录（历史累计）
2. **ExerciseRoute**: 所有 `status='started'` 或 `status='completed'` 的路线（历史累计）

**计算公式**:
```
totalCaloriesBurned = FoodRecord累计消耗 + ExerciseRoute累计消耗
totalExerciseMinutes = FoodRecord累计时长 + ExerciseRoute累计时长
totalDistance = FoodRecord累计距离 + ExerciseRoute累计距离
```

**后端查询逻辑**:
```javascript
// 1. 获取所有 FoodRecord 消耗记录
const allConsumeRecords = await FoodRecord.find({
  user: req.user._id,
  type: 'consume'
});
```

### GoalProgress.vue - 目标进度

**API**: `GET /api/stats/goal-progress`

**数据来源**: 同 DailySummaryCard，使用今日运动数据计算进度

**计算公式**:
- **减重 (lose)**: 进度 = (消耗的热量 / 目标消耗) * 100
- **增重 (gain)**: 进度 = (摄入的热量 / 目标摄入) * 100
- **维持 (maintain)**: 进度 = (运动消耗 / 目标消耗) * 100

## 🔄 数据更新流程

### 用户点击"启动高德地图开始运动"按钮

```
1. 前端调用 startExercise(routeId)
   ↓
2. POST /api/route/:routeId/start
   ↓
3. 后端处理:
   - 更新路线状态: generated → started
   - 创建 FoodRecord 消耗记录（使用估算值）
   - 更新用户 totalStats（累计消耗、时长、距离）
   ↓
4. 前端触发 exercise-started 事件
   ↓
5. 所有组件自动刷新:
   - DailySummaryCard.refresh()
   - StatsCard.refresh()
   - GoalProgress.refresh()
```

## ⚠️ 重要说明

### 为什么数据没有更新？

1. **路线状态必须是 `started` 或 `completed`**
   - 路线刚生成时状态是 `generated`
   - 只有点击开始运动后，状态才会变成 `started`
   - **统计API只查询 `started` 或 `completed` 状态的路线**
   - 如果 start 接口调用失败（404），状态就不会更新，统计就查不到数据

2. **API路径必须正确**
   - 修复前: `/api/route/generate/:routeId/start` ❌ (404)
   - 修复后: `/api/route/:routeId/start` ✅

3. **数据查询逻辑**
   - 先查询所有今日路线（包括所有状态）
   - 然后过滤出 `started` 或 `completed` 状态的路线
   - 只统计这些已开始/已完成的路线
